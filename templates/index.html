welcome to colesurfs

i designed this dashboard for staying on top of the swell forecast for the northeast

it is exactly the data i use for forecasting, consolidated into one interface

claude helped with the code, you can review it on github

for my main site, visit coleheine.com

tips
  • tap on a buoy name to reveal associated spot data for that buoy; tap it again to return to the overview
  • tap on the name of a spot to link to Surfline's live camera
  • compare the GFS and Euro models to get a sense of how reliable the forecast is: model agreement = more reliable forecast
  • this site works best as a web app: tap 3 dot menu, then share, then add to homescreen

∿colesurfs · iOS widgets
setup
  1. Install Scriptable from the App Store.
  2. In Scriptable, make a new script named colesurfs and paste this loader: 
    const r = new Request("https://surfreport.coleheine.com/widget/colesurfs.js");
await eval(await r.loadString());
  3. Add a Scriptable widget to the home screen, long-press it → Edit Widget, pick the colesurfs script and set the Parameter from the table.

notes
  • Small shows 1 region, medium 2, large 4. Live widgets are medium only.
  • Widgets refresh on iOS's schedule, about every 30 minutes. Tapping a forecast widget opens this site; a live widget opens the spot's Surfline page.
  • If the image shows margins, append ; size=WxH with the numbers the calibrate ruler gives, e.g. live-lido; size=360x169.
